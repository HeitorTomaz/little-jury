# Candidate names

*Material from round 2 on, for the players and the publishing specialist.*

The game has no name yet. Below are five candidates, listed in alphabetical order. The order does not indicate the author's preference. When passing the list to an agent, draw the order again.

| Name | Literal meaning of the parts |
|---|---|
| Beacon & Brine | "beacon" is a signal light; "brine" is salty sea water |
| Glimmerock | "glimmer" is a faint light; "rock" is the island |
| Lampwright | an old-style word for someone who makes or tends lamps |
| Tidewatch | "tide" is the sea's rise and fall; "watch" is a shift of guard |
| Two Keepers | the two players, as lighthouse keepers |

The author searched the web for games with the same or a similar name and found no direct conflict. The search did not cover the stores' internal catalogs or trademark registries.
